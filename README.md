# BrewLite - Ứng dụng đặt đồ uống

## 🛠 Cách cài đặt và chạy dự án

Dự án này là một Monorepo bao gồm cả **Frontend (Next.js)** và **Backend (NestJS)**.

### **1. Chạy Backend (NestJS)**
Mở một terminal mới và chạy các lệnh sau:
```bash
cd backend
npm install
npm run start:dev
```
*Backend sẽ chạy ở cổng `http://localhost:3001`*

### **2. Chạy Frontend (Next.js)**
Mở một terminal mới khác và chạy các lệnh sau:
```bash
cd frontend
npm install
npm run dev
```
*Frontend sẽ chạy ở cổng `http://localhost:3000`*
